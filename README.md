# filmORG

Sistema de gerenciamento de produção audiovisual com interface moderna e responsiva.

## Sobre o Projeto

O filmORG é uma aplicação web desenvolvida para auxiliar na gestão de produções audiovisuais, oferecendo ferramentas para:

- Gerenciamento de projetos
- Controle de roteiros
- Gestão de equipe
- Controle de equipamentos
- Analytics e relatórios
- Agenda de produção
- Gestão orçamentária

## Tecnologias Utilizadas

- HTML5
- CSS3 (com variáveis CSS e flexbox)
- JavaScript (Vanilla)
- Chart.js para visualizações
- Remix Icon para ícones

## Estrutura do Projeto

- `index.html` - Página inicial com redirecionamento
- `dashboard.html` - Dashboard principal
- `base.css` - Estilos base do sistema
- `layout.js` - Script para padronização do layout

## Instalação

1. Clone o repositório
2. Abra o arquivo `index.html` em um navegador moderno
3. O sistema redirecionará automaticamente para o dashboard
